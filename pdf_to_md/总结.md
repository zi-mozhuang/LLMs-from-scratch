第 1 章 理解大语言模型

本章内容

大语言模型（LLM）基本概念的高层次解释
LLM 所基于的 Transformer 架构的见解
从零构建 LLM 的计划

LLM 是近年来开发的深度神经网络模型，开创了自然语言处理（NLP）的新时代。在 LLM 出现之前，传统方法擅长分类任务（如垃圾邮件分类）和可通过手工规则或简单模型捕获的模式识别，但在需要复杂理解和生成能力的语言任务上表现不佳。

LLM 具有理解、生成和解释人类语言的卓越能力。需要澄清的是，当我们说语言模型"理解"时，我们指的是它们能够以看似连贯和上下文相关的方式处理和生成文本，而非它们拥有人类般的意识或理解能力。

1.1 什么是 LLM？

LLM 是一种旨在理解、生成和响应类人文本的神经网络。这些模型是在海量文本数据上训练的深度神经网络，有时包含互联网上公开可用文本的很大一部分。

"大语言模型"中的"大"既指模型的参数规模，也指其训练所用的庞大数据集。这类模型通常有数十亿甚至数千亿参数——这些参数是网络中在训练过程中被优化以预测序列中下一个词的可调整权重。

下一个词预测任务之所以合理，是因为它利用了语言固有的序列性来训练模型理解上下文、结构和文本中的关系。

图 1.1: AI、机器学习、深度学习与 LLM 的层次关系：

人工智能（AI）
└── 机器学习（ML）
    └── 深度学习（DL）
        └── 大语言模型（LLM）

AI: 具有类人智能的系统
机器学习: 从数据中自动学习规则的算法
深度学习: 由多层神经网络构成的机器学习
LLM: 用于解析和生成类人文本的深度神经网络

LLM 的应用领域广泛：

1.3 构建和使用 LLM 的阶段

为什么要自己构建 LLM？从零编码 LLM 是理解其机制和局限性的绝佳练习。此外，它还为我们提供了将现有开源 LLM 架构预训练或微调到自己领域特定数据集或任务所需的知识。

研究表明，在模型性能方面，针对特定任务或领域定制的 LLM 可以超越通用 LLM（如 ChatGPT）。例子包括 BloombergGPT（金融领域专用）和为医学问答定制的 LLM。

创建 LLM 的一般过程包括预训练和微调：

预训练: 在大型、多样的数据集上训练，发展对语言的广泛理解
微调: 在更窄的、特定于任务或领域的数据集上进一步训练

两类流行的微调方式：
指令微调: 数据集由指令-答案对组成
分类微调: 数据集由文本及其类别标签组成（如垃圾邮件/非垃圾邮件）

注意: LLM 通常使用 PyTorch 深度学习库实现。附录 A 提供了 PyTorch 的全面介绍。

1.4 Transformer 架构简介

大多数现代 LLM 依赖于 Transformer 架构，该架构在 2017 年的论文 "Attention Is All You Need"（https://arxiv.org/abs/1706.03762）中提出。

Transformer 架构由两个子模块组成：

编码器（Encoder）: 处理输入文本，将其编码为一系列捕获上下文信息的数值表示（向量）
解码器（Decoder）: 接收编码向量并生成输出文本

后续变体：

BERT（Bidirectional Encoder Representations from Transformers）: 基于编码器，专注于掩码词预测，擅长文本分类任务
GPT（Generative Pretrained Transformers）: 专注于解码器部分，为生成任务设计

| 特性 | BERT | GPT |
|------|------|-----|
| 基础 | Transformer 编码器 | Transformer 解码器 |
| 训练方式 | 掩码词预测 | 逐词生成 |
| 主要用途 | 文本分类 | 文本生成 |

GPT 模型擅长零样本（zero-shot）和少样本（few-shot）学习任务：

零样本学习: 无需任何先前示例即可泛化到全新任务
少样本学习: 从用户提供的少量示例中学习

2.1 理解词嵌入

深度神经网络模型（包括 LLM）无法直接处理原始文本。由于文本是类别型的，它与用于实现和训练神经网络的数学运算不兼容。因此，我们需要一种将词表示为连续值向量的方法。

将数据转换为向量格式的概念通常称为嵌入（embedding）。

嵌入的核心是将离散对象（如词、图像甚至整个文档）映射到连续向量空间中的点。

词嵌入的维度可以从 1 到数千不等。较高的维度可能捕获更细微的关系，但代价是计算效率：

最小的 GPT-2 模型（117M 和 125M 参数）使用 768 维的嵌入大小
最大的 GPT-3 模型（175B 参数）使用 12,288 维的嵌入大小

python
class SimpleTokenizerV1:
    def init(self, vocab):
        self.strtoint = vocab
        self.inttostr = {i: s for s, i in vocab.items()}

    def encode(self, text):
        preprocessed = re.split(r'([,.?_!"()\'"]|--|\s)', text)
        preprocessed = [item.strip() for item in preprocessed if item.strip()]
        ids = [self.strtoint[s] for s in preprocessed]
        return ids

    def decode(self, ids):
        text = " ".join([self.inttostr[i] for i in ids])
        text = re.sub(r'\s+([,.?!"()\'])', r'\1', text)
        return text

                         shuffle=True, droplast=True, numworkers=0):

    dataset = GPTDatasetV1(txt, tokenizer, max_length, stride)

3.1 长序列建模的问题

在 Transformer 出现之前，循环神经网络（RNN）是语言翻译最流行的编码器-解码器架构。

编码器-解码器 RNN 的局限：RNN 在解码阶段无法直接访问编码器的早期隐藏状态，只能依赖当前隐藏状态，这可能导致上下文丢失。

3.2 使用注意力机制捕获数据依赖

2014 年，研究人员开发了 Bahdanau 注意力机制，修改编码器-解码器 RNN，使解码器能在每个解码步骤选择性地访问输入序列的不同部分。

2017 年，研究人员提出了包含自注意力机制的原始 Transformer 架构。

自注意力是一种机制，允许输入序列中的每个位置在计算序列表示时考虑同一序列中所有其他位置的相关性。

为什么叫 query、key、value？ 这些术语借自信息检索和数据库领域。Query 类似搜索查询，Key 类似用于索引的数据库键，Value 类似键值对中的值。

代码清单 3.1: 紧凑的自注意力类
python
import torch.nn as nn

class SelfAttention_v1(nn.Module):
    def init(self, din, dout):
        super().init()
        self.Wquery = nn.Parameter(torch.rand(din, d_out))
        self.Wkey = nn.Parameter(torch.rand(din, d_out))
        self.Wvalue = nn.Parameter(torch.rand(din, d_out))

    def forward(self, x):
        keys = x @ self.W_key
        queries = x @ self.W_query
        values = x @ self.W_value
        attn_scores = queries @ keys.T  # omega
        attnweights = torch.softmax(attnscores / keys.shape[-1]0.5, dim=-1)
        contextvec = attnweights @ values
        return context_vec

代码清单 3.2: 使用 PyTorch Linear 层的自注意力类
python
class SelfAttention_v2(nn.Module):
    def init(self, din, dout, qkv_bias=False):
        super().init()
        self.Wquery = nn.Linear(din, dout, bias=qkvbias)
        self.Wkey = nn.Linear(din, dout, bias=qkvbias)
        self.Wvalue = nn.Linear(din, dout, bias=qkvbias)

    def forward(self, x):

        queries = self.W_query(x)
        values = self.W_value(x)
        attn_scores = queries @ keys.T
        attnweights = torch.softmax(attnscores / keys.shape[-1]0.5, dim=-1)
        contextvec = attnweights @ values
        return context_vec

缩放的原因: 通过嵌入维度归一化以避免小梯度。当嵌入维度较大（GPT 类 LLM 通常大于 1000）时，大的点积会由于 softmax 函数导致反向传播中梯度非常小。

因果注意力（也称为掩码注意力）是自注意力的专门形式，它限制模型在计算注意力分数时只考虑序列中先前和当前的输入。我们屏蔽对角线上方的注意力权重。

3.5.3 实现紧凑的因果注意力类

代码清单 3.3: 紧凑的因果注意力类
python
class CausalAttention(nn.Module):
    def init(self, din, dout, contextlength, dropout, qkvbias=False):
        super().init()
        self.dout = dout
        self.Wquery = nn.Linear(din, dout, bias=qkvbias)
        self.Wkey = nn.Linear(din, dout, bias=qkvbias)
        self.Wvalue = nn.Linear(din, dout, bias=qkvbias)
        self.dropout = nn.Dropout(dropout)
        self.register_buffer(
            'mask',
            torch.triu(torch.ones(contextlength, contextlength), diagonal=1)
        )

    def forward(self, x):
        b, numtokens, din = x.shape
        keys = self.W_key(x)
        queries = self.W_query(x)
        values = self.W_value(x)

        attn_scores = queries @ keys.transpose(1, 2)
        attnscores.maskedfill_(
            self.mask.bool()[:numtokens, :numtokens], -torch.inf)
        attnweights = torch.softmax(attnscores / keys.shape[-1]0.5, dim=-1)
        attnweights = self.dropout(attnweights)
        contextvec = attnweights @ values
        return context_vec

使用示例（支持批处理）：

class MultiHeadAttentionWrapper(nn.Module):
    def init(self, din, dout, contextlength, dropout, numheads, qkv_bias=False):
        super().init()
        self.heads = nn.ModuleList(
            [CausalAttention(din, dout, contextlength, dropout, qkvbias)
             for  in range(numheads)]

    def forward(self, x):
        return torch.cat([head(x) for head in self.heads], dim=-1)

3.6.2 使用权重拆分实现多头注意力

代码清单 3.5: 高效的多头注意力类
python
class MultiHeadAttention(nn.Module):
    def init(self, din, dout, contextlength, dropout, numheads, qkv_bias=False):
        super().init()
        assert dout % numheads == 0, "dout must be divisible by numheads"

        self.dout = dout
        self.numheads = numheads
        self.headdim = dout // num_heads

        self.Wquery = nn.Linear(din, dout, bias=qkvbias)
        self.Wkey = nn.Linear(din, dout, bias=qkvbias)
        self.Wvalue = nn.Linear(din, dout, bias=qkvbias)
        self.outproj = nn.Linear(dout, d_out)
        self.dropout = nn.Dropout(dropout)
        self.register_buffer(
            "mask",
            torch.triu(torch.ones(contextlength, contextlength), diagonal=1)
        )

    def forward(self, x):
        b, numtokens, din = x.shape

        keys = self.W_key(x)
        queries = self.W_query(x)
        values = self.W_value(x)

        keys = keys.view(b, numtokens, self.numheads, self.head_dim)
        values = values.view(b, numtokens, self.numheads, self.head_dim)
        queries = queries.view(b, numtokens, self.numheads, self.head_dim)

        keys = keys.transpose(1, 2)
        queries = queries.transpose(1, 2)
        values = values.transpose(1, 2)

        attn_scores = queries @ keys.transpose(2, 3)
        maskbool = self.mask.bool()[:numtokens, :num_tokens]
        attnscores.maskedfill(maskbool, -torch.inf)

        attnweights = torch.softmax(attnscores / keys.shape[-1]0.5, dim=-1)
        attnweights = self.dropout(attnweights)

        contextvec = (attnweights @ values).transpose(1, 2)
        contextvec = contextvec.contiguous().view(b, numtokens, self.dout)
        contextvec = self.outproj(context_vec)
        return context_vec

4.2 使用层归一化归一化激活

层归一化的主要思想是调整神经网络层的激活（输出），使其均值为 0、方差为 1（单位方差）。

代码清单 4.2: 层归一化类
python
class LayerNorm(nn.Module):
    def init(self, emb_dim):
        super().init()
        self.eps = 1e-5
        self.scale = nn.Parameter(torch.ones(emb_dim))
        self.shift = nn.Parameter(torch.zeros(emb_dim))

    def forward(self, x):
        mean = x.mean(dim=-1, keepdim=True)
        var = x.var(dim=-1, keepdim=True, unbiased=False)
        norm_x = (x - mean) / torch.sqrt(var + self.eps)
        return self.scale * norm_x + self.shift

scale 和 shift 是两个可训练参数，LLM 在训练期间自动调整它们。

有偏方差: 使用 unbiased=False 进行方差计算，不做贝塞尔校正，以兼容 GPT-2 模型的归一化层。

4.3 使用 GELU 激活实现前馈网络

GELU（Gaussian Error Linear Unit）是比 ReLU 更复杂、更平滑的激活函数。

代码清单 4.3: GELU 激活函数的实现
python
class GELU(nn.Module):
    def init(self):
        super().init()

    def forward(self, x):
        return 0.5  x  (1 + torch.tanh(
            torch.sqrt(torch.tensor(2.0 / torch.pi)) *
            (x + 0.044715 * torch.pow(x, 3))
        ))

代码清单 4.4: 前馈神经网络模块

class FeedForward(nn.Module):

        super().init()
        self.layers = nn.Sequential(
            nn.Linear(cfg["embdim"], 4 * cfg["embdim"]),
            GELU(),
            nn.Linear(4 * cfg["embdim"], cfg["embdim"]),
        )

    def forward(self, x):
        return self.layers(x)

class ExampleDeepNeuralNetwork(nn.Module):
    def init(self, layersizes, useshortcut):
        super().init()
        self.useshortcut = useshortcut
        self.layers = nn.ModuleList([
            nn.Sequential(nn.Linear(layersizes[0], layersizes[1]), GELU()),
            nn.Sequential(nn.Linear(layersizes[1], layersizes[2]), GELU()),
            nn.Sequential(nn.Linear(layersizes[2], layersizes[3]), GELU()),
            nn.Sequential(nn.Linear(layersizes[3], layersizes[4]), GELU()),
            nn.Sequential(nn.Linear(layersizes[4], layersizes[5]), GELU())

        for layer in self.layers:
            layer_output = layer(x)
            if self.useshortcut and x.shape == layeroutput.shape:
                x = x + layer_output
            else:
                x = layer_output
        return x

from chapter03 import MultiHeadAttention

class TransformerBlock(nn.Module):
    def init(self, cfg):
        super().init()
        self.att = MultiHeadAttention(
            din=cfg["embdim"],
            dout=cfg["embdim"],
            contextlength=cfg["contextlength"],
            numheads=cfg["nheads"],
            dropout=cfg["drop_rate"],
            qkvbias=cfg["qkvbias"])
        self.ff = FeedForward(cfg)
        self.norm1 = LayerNorm(cfg["emb_dim"])
        self.norm2 = LayerNorm(cfg["emb_dim"])
        self.dropshortcut = nn.Dropout(cfg["droprate"])

    def forward(self, x):
        # 注意力块的快捷连接
        shortcut = x
        x = self.norm1(x)
        x = self.att(x)
        x = self.drop_shortcut(x)
        x = x + shortcut

        # 前馈块的快捷连接
        shortcut = x
        x = self.norm2(x)
        x = self.ff(x)
        x = self.drop_shortcut(x)
        x = x + shortcut

        return x

这称为 Pre-LayerNorm（层归一化在组件之前）。较旧的架构使用 Post-LayerNorm。

        batchsize, seqlen = in_idx.shape
        tokembeds = self.tokemb(in_idx)
        posembeds = self.posemb(torch.arange(seqlen, device=inidx.device))
        x = tokembeds + posembeds
        x = self.drop_emb(x)
        x = self.trf_blocks(x)
        x = self.final_norm(x)
        logits = self.out_head(x)
        return logits

6.1 微调的不同类别

两种最常见的微调方式：

指令微调: 使用指令和答案对训练模型
分类微调: 训练模型识别特定类别标签集

分类微调模型局限于预测训练期间遇到的类别。指令微调模型通常能处理更广泛的任务。

选择合适的方案：
指令微调最适合需要处理各种基于复杂用户指令任务的模型
分类微调非常适合需要将数据精确分类为预定义类别的项目
指令微调需要更大的数据集和更多计算资源
分类微调需要更少的数据和计算能力

class SpamDataset(Dataset):
    def init(self, csvfile, tokenizer, maxlength=None, padtokenid=50256):
        self.data = pd.readcsv(csvfile)
        self.encoded_texts = [
            tokenizer.encode(text) for text in self.data["Text"]
        ]

        if max_length is None:

        else:
            self.maxlength = maxlength
            self.encoded_texts = [
                encodedtext[:self.maxlength]
                for encodedtext in self.encodedtexts
            ]

        self.encoded_texts = [
            encodedtext + [padtokenid] * (self.maxlength - len(encoded_text))
            for encodedtext in self.encodedtexts
        ]

    def getitem(self, index):
        encoded = self.encoded_texts[index]
        label = self.data.iloc[index]["Label"]
        return (
            torch.tensor(encoded, dtype=torch.long),
            torch.tensor(label, dtype=torch.long)
        )

    def len(self):
        return len(self.data)

    def longestencoded_length(self):
        max_length = 0
        for encodedtext in self.encodedtexts:
            encodedlength = len(encodedtext)
            if encodedlength > maxlength:
                maxlength = encodedlength
        return max_length

代码清单 7.5: 实现自定义批次整理函数
python
def customcollatefn(
        batch,
        padtokenid=50256,
        ignore_index=-100,
        allowedmaxlength=None,
        device="cpu"
):
    batchmaxlength = max(len(item)+1 for item in batch)
    inputslst, targetslst = [], []

    for item in batch:
        new_item = item.copy()
        newitem += [padtoken_id]

        padded = (
            newitem + [padtokenid] * (batchmaxlength - len(newitem))
        )
        inputs = torch.tensor(padded[:-1])
        targets = torch.tensor(padded[1:])

        mask = targets == padtokenid
        indices = torch.nonzero(mask).squeeze()
        if indices.numel() > 1:
            targets[indices[1:]] = ignore_index

        if allowedmaxlength is not None:
            inputs = inputs[:allowedmaxlength]
            targets = targets[:allowedmaxlength]

        inputs_lst.append(inputs)
        targets_lst.append(targets)

    inputstensor = torch.stack(inputslst).to(device)
    targetstensor = torch.stack(targetslst).to(device)
    return inputstensor, targetstensor

附录 E: 使用 LoRA 的参数高效微调

E.1 LoRA 简介

LoRA（Low-Rank Adaptation）是参数高效微调的最广泛使用的技术之一。

常规微调中的权重更新：

$$W_{updated} = W + \Delta W$$

LoRA 通过学习近似值来计算权重更新：

$$\Delta W \approx AB$$

其中 A 和 B 是比 W 小得多的两个矩阵。

然后：

$$W_{updated} = W + AB$$

E.4 使用 LoRA 的参数高效微调

代码清单 E.5: 实现 LoRA 层
python
import math

class LoRALayer(torch.nn.Module):
    def init(self, indim, outdim, rank, alpha):
        super().init()
        self.A = torch.nn.Parameter(torch.empty(in_dim, rank))
        torch.nn.init.kaiminguniform(self.A, a=math.sqrt(5))
        self.B = torch.nn.Parameter(torch.zeros(rank, out_dim))
        self.alpha = alpha

    def forward(self, x):
        x = self.alpha * (x @ self.A @ self.B)
        return x

代码清单 E.6: 用 LinearWithLoRA 层替换 Linear 层
python
class LinearWithLoRA(torch.nn.Module):
    def init(self, linear, rank, alpha):
        super().init()
        self.linear = linear
        self.lora = LoRALayer(
            linear.infeatures, linear.outfeatures, rank, alpha)

    def forward(self, x):
        return self.linear(x) + self.lora(x)

def replacelinearwith_lora(model, rank, alpha):
    for name, module in model.named_children():
        if isinstance(module, torch.nn.Linear):
            setattr(model, name, LinearWithLoRA(module, rank, alpha))
        else:
            replacelinearwith_lora(module, rank, alpha)
